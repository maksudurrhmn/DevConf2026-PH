# DevConf 2026

A modern and responsive landing page for **DevConf 2026**, a fictional developer conference designed to bring together developers, engineers, and tech enthusiasts.

## Live Demo

[View Live Website](https://maksudurrhmn.github.io/DevConf2026-PH/)

## Features

- **Modern Landing Page:** Clean and professional design with an engaging hero section.
- **Speakers Section:** Highlights featured speakers and their professional backgrounds.
- **Pricing Plans:** Displays Standard, Pro, and Team ticket packages.
- **Workshops & Hackathons:** Showcases interactive learning tracks covering AI Engineering, Cloud-Native Architecture, and Modern Frontend Development.
- **Responsive Design:** Optimized layout for different screen sizes.
- **Custom UI Elements:** Includes custom buttons, icons, typography, and visual components.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Inter)

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/maksudurrhmn/DevConf2026-PH.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DevConf2026-PH
   ```

3. Open `index.html` in your browser.
